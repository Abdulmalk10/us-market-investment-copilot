# Output standard

Lead with the conclusion and as-of timestamp. Use the smallest useful structure:

1. View and confidence
2. Why now
3. Evidence and key numbers
4. Bull/base/bear scenarios
5. Trigger, invalidation, horizon, and reward-to-risk
6. Key risks and what would change the view
7. Sources and data limitations

Never guarantee performance. Avoid personalized suitability claims unless the user supplies objectives, constraints, and risk tolerance. Clearly distinguish research from individualized financial advice.
