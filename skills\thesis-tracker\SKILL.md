# Thesis Tracker

Represent each thesis with ticker, creation date, horizon, thesis statement, key assumptions, catalysts and dates, entry condition, invalidation rules, risks, and review cadence.

On update, distinguish new facts from changed interpretation. Mark each thesis as intact, strengthening, weakening, invalidated, or expired. Explain the minimum evidence for the status. Do not move invalidation thresholds simply to preserve a losing thesis.

Monitoring is read-only unless the user explicitly asks to save or update an artifact. A reminder or recurring monitor must be created only when explicitly requested.
